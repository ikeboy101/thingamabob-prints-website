THINGAMABOB PRINTS — WEBSITE STARTER

WHAT'S INCLUDED
- Home, Gallery, Shop, Custom Orders, About and Contact pages
- Mobile-responsive layout and navigation
- Gallery category filters
- Etsy and Instagram link placeholders
- Custom request and contact forms that prepare an email
- Colorful SVG product placeholders you can replace with real product photography

BEFORE PUBLISHING
1. The business name is already set to Thingamabob Prints.
2. Open assets/site.js and add your Etsy URL, Instagram URL and real business email.
3. Replace the six SVG images in assets/ with your own product photos (or update the image paths in the HTML).
4. Update the About page with your story and the product descriptions with accurate details.
5. Add your policies before accepting direct orders: shipping, returns, privacy, terms and product/material safety information.

HOW TO PREVIEW
- Open index.html in a browser. For the best local preview, use a simple static server such as VS Code Live Server.
- All pages are static HTML/CSS/JS and do not require a paid framework or database.

FREE HOSTING
- This is a static site and can be hosted on GitHub Pages, Cloudflare Pages or Netlify free tiers, subject to each provider's current plan limits.
- A custom domain is optional for the first launch; each host can provide a free subdomain.
- To publish using GitHub Pages: create a public GitHub repository, upload the contents of this folder (not the ZIP itself), then enable Pages in repository Settings > Pages and choose deploy from the main branch/root.
- The GitHub connection is ready. After you create the public repository, the site files can be uploaded through the connected GitHub account.

IMPORTANT LIMITATIONS
- This starter does not yet process payments, calculate shipping, store customer data or manage inventory.
- Etsy checkout is the easiest first step. A standalone store will need a payment provider and secure backend or commerce platform; hosting can remain free, but payment processing fees will apply.
- The forms open the visitor's email app; they are not a hosted form inbox. For reliable form submissions, connect a form service or backend later.
